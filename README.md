A deterministic 1024×1024 Pillow-generated summary of 36 dated stories across 8 regions from Thursday 26 November 2026. The program uses only Python and Pillow, needs no network access, and writes `entry.png` to `MAKEFUN_OUTPUT_DIR` (or `/output` when unset).

Run with:

```sh
python3 main.py
```
